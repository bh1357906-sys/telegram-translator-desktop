语言

每个聊天可以在右下角的语言按钮单独设置，会自动记住。

行为

草稿里没有中文时（直接打外语、或用了助手建议）会原样发送，不再翻译。翻译失败时消息不会发出。对方消息里出现疑似“给 AI 下指令”的内容时，发送前会强制预览一次。
要和 WhatsApp / Telegram 自己的设置一致。选了 Ctrl+回车后：Ctrl+回车 = 翻译并发送，Alt+回车 = 直接发原文。

词库

发送和接收时都会生效：消息里出现这些词，就按你写的译法翻。产品名、价格说法、公司名特别适合放这里。译文下面点「不准」→「手动修正」也会加进来。

语音

DeepSeek 不能识别语音，需要单独一个 Key。推荐 Groq：到 console.groq.com 注册 → API Keys → Create，费用很低（约 0.3 元 / 小时语音）。选 OpenAI 则和上面 OpenAI 的翻译 Key 共用。
高级：语音识别接口地址 / 模型

发语音

ElevenLabs：到 elevenlabs.io 注册 → 右下角头像 → API Keys → Create。免费档每月 1 万字符可以试效果；克隆自己的声音需要 Starter（约 5 美元/月）以上。一条 100 字的语音大约 1～2 毛钱。
用 OpenAI 的 Key（和翻译 / 语音识别选 OpenAI 时共用）。一条 100 字的语音大约 1 分钱。声音偏“播音”，想要更像真人请选 ElevenLabs。
没拉取前只显示几个 ElevenLabs 自带的声音；拉取后会列出你账号里全部可用的声音（包括在 ElevenLabs 声音库里添加过的和克隆的）。
当场录 1～2 分钟你自己的声音（随便聊点什么，像平时发语音那样，别念稿），上传后以后发出的语音条就是“你本人”在说外语。只能录，不能传文件——不允许拿别人的声音。

API 请求代理

翻译、语音、识图请求默认从本机直连发出，不会走账号的代理。如果你需要这些请求也经过代理（比如隐藏本机 IP 或所在地区访问不到），在这里单独设置。
SOCKS 代理不支持用户名密码（浏览器内核限制）。
