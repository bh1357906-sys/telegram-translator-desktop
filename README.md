# TG Translator（Windows 桌面版）

加载官方 Telegram Web（K 版）：聊天消息自动翻译成你的语言；你用中文打字，按回车自动翻译成对方语言再发出。自带 API Key（DeepSeek / OpenAI / Gemini / 任意 OpenAI 兼容接口），无后端，不碰聊天协议。

Mac 用户请用 Chrome 插件版（`translator-chrome-extension`），功能相同。

## 功能

- **自动翻译消息** — 每条消息下面显示一行译文。只翻译屏幕附近的消息，最多同时 3 个请求，结果缓存在本机，重启不重复花钱。
- **回车自动翻译发送** — 草稿有中文时，按回车 / 点发送会先翻译再发；翻译失败**不会发出原文**，草稿保留。
  - `Ctrl+Enter`：不翻译，直接发原文。
  - 草稿里没有中文（直接打外语、纯表情、链接）→ 原样发送，不调接口。
  - `Shift+Enter` 换行；`Alt+T` 或「译」按钮只翻译草稿不发送。
- **每个聊天单独记语言** — 右下角语言按钮切换，自动记住；新聊天用设置里的默认语言。
- **多账号 + 每个账号独立代理（独立 IP）** — 窗口左侧是账号栏，点「＋」添加账号，每个账号登录数据完全独立、同时在线，Ctrl+1～9 切换。右键（或双击）账号头像可设置代理：支持 HTTP / HTTPS / SOCKS5 / SOCKS4，可直接粘贴代理链接自动识别，「测试代理」会显示出口 IP 和地区。开了代理的账号会屏蔽 WebRTC 走真实 IP。注意：SOCKS 代理不支持用户名密码（浏览器内核限制），需要账号密码的代理请选 HTTP。
- **账号分组** — 账号多的时候可以分组（比如按团队）：账号栏点「▤」新建分组，或者编辑账号时填「分组」。点组名可以折叠 / 展开，折叠后显示组里的未读数；右键组名可以改名、调整顺序、删除分组（账号保留）。
- **中英文界面** — 设置 → 界面语言，可切换成 English：设置页、账号栏、菜单、聊天页里的按钮和提示都会变成英文。
- **语音转文字翻译** — 对方的语音消息下面有「🎤 转文字并翻译」，点一下（或自己点播放）就显示说了什么和中文意思；工具栏的 🎤 按钮：说中文，自动识别后翻译成对方语言填进输入框（不会自动发送）。DeepSeek 不支持语音，需要在设置 → 语音里另填一个 Groq（推荐，便宜）或 OpenAI 的 Key。
- **悬浮按钮可拖动** — 按住任意按钮拖到合适位置，会记住；语言面板里可以一键恢复默认位置。
- **用量统计** — 语言面板和设置页显示今天 / 本月的请求次数和 tokens。
- **更新提示** — 启动后自动检查 GitHub Release，有新版本会弹窗询问；你点「下载」才下载，下载完再确认一次才安装（exe 没有代码签名，所以不做静默安装）。
- **发语音条（🔊）** — 输入框里打好中文，点 🔊（或 Alt+V）：翻译成对方语言 → 合成语音 → 当作普通语音条发出去（对方看到的就是带波形的语音消息，不是音频文件）。发送前可以改译文、换男声/女声、试听。语音合成默认用 ElevenLabs（最像真人；设置 → 发语音 → 填 ElevenLabs 的 Key，可以拉取账号里的全部声音），还可以**当场录 1～2 分钟克隆自己的声音**，以后发出的语音条就是你本人在说外语（只能录不能传文件，不允许用别人的声音）。也支持 OpenAI 的合成。发出去的语音条下面会显示译文和原文。失败时不会退化成发文件，草稿会放回输入框。
- **图片翻译（🖼）** — 截图、报价单、聊天截图等图片下面有「🖼 翻译图片」，点一下识别图里的文字并翻译。需要支持识图的引擎（OpenAI / Gemini），DeepSeek 不支持。
- **译文反馈** — 鼠标移到译文上出现「换一种 / 修正 / 复制」：不准就换一种译法；手动修正后这条消息以后直接显示你改的，短句还可以一键加进词库。
- **常用语** — 设置里每行一条，输入框里打 `/` 弹出来选（可以继续打字筛选），选中后自动翻译填入。
- **账号级设置** — 编辑账号时可以单独设默认对方语言、语气、翻译引擎（比如对马来西亚客户的号默认马来语，重要客户的号用 OpenAI），留空就跟随全局。
- **预算** — 设置里填每月 tokens 预算，超出后提醒，或自动切到 DeepSeek。
- **API 请求代理** — 翻译 / 语音 / 识图请求默认从本机直连，**不走账号代理**；如需经过代理，在设置 → API 请求代理里单独设置（直连 / 跟随系统 / 固定代理）。
- **托盘与通知** — 关闭窗口缩到系统托盘（可关），窗口不在前台时新消息的译文用系统通知显示，点通知切到对应账号。
- **发送前防护** — 对方最近的消息里出现疑似“给 AI 下指令”的内容、或译文长度明显不对时，发送前会强制预览一次。
- **本机数据加密** — API Key、代理密码、译文缓存、聊天助手的记录和档案都用 Windows 系统加密（DPAPI）保存；设置页可以一键清除。

## 发布新版本

1. 改 `package.json` 里的 `version`（例如 `0.3.1`）。
2. 提交后打标签并推送：`git tag v0.3.1 && git push --tags`。
3. GitHub Actions 自动打包 exe，并把 `exe`、`.blockmap`、`latest.yml` 一起上传到 Release（**自动更新靠这三个文件**，不要删）。
4. 已安装的用户下次启动会收到更新提示，确认后下载安装。

> `package-lock.json` 要一起提交：CI 用 `npm ci` 按锁文件精确安装。

## 本地开发

```bash
npm install
npm start       # 会先打包 preload（dist-preload/），再启动
npm test        # 打包 + 单元测试
npm run dist    # 本机打 Windows 安装包
```

聊天页面开了沙箱（`sandbox: true`），所以 `preload.js` 及其依赖的 `core/` 会先用 esbuild 打成 `dist-preload/preload.js`（`npm run build`）。改了 `core/` 或 `preload.js` 要重新 `npm run build`（`npm start` 自动做）。

## 代码结构

```
main.js               应用配置（网址、名称、更新仓库）
preload.js            页面适配器：Telegram Web（K 版） 的所有选择器都在这里
core/                 通用逻辑（WA / TG 两个项目完全相同，改一边要同步到另一边）
  lang.js             语言列表、中/日/韩文字识别、发送前检查
  service.js          翻译服务：设置、队列、缓存、重试、用量（桌面版和插件共用）
  main-core.js        Electron 主进程：窗口、菜单、托盘、通知、更新、API 请求代理、输入框写入
  accounts.js         多账号：独立登录数据、独立代理、出口 IP 检测
  voice-hook.js       语音消息抓取（注入网页主环境，播放时读出本地音频）
  i18n.js             界面语言（中文 / English 词典）
  proxy.js            代理链接解析、代理规则
  renderer-core.js    页面：翻译行、发送拦截、工具栏和面板
scripts/build-preload.js  用 esbuild 打包页面 preload
settings.*            设置窗口
shell.*               左侧账号栏 + 添加/编辑账号
test/                 单元测试
```

## 已知限制

- 贴纸不翻译；图片翻译需要 OpenAI / Gemini 引擎。
- 如果 WhatsApp / Telegram 里把发送键改成了 Ctrl+Enter，设置 → 「聊天软件里的发送键」要选成一致，否则回车的行为会对不上。
- 网页版改版后如果翻译不出现或回车不翻译，只需要更新 `preload.js` 里的选择器。
- exe 没有代码签名，首次运行 Windows 会提示「未知发布者」，点「更多信息 → 仍要运行」。
- 消息文本会发送到你选择的翻译服务商，按 token 计费。
- 遇到“按回车发出去的是原文”这类问题，把 `%APPDATA%\\TG Translator\\translator.log` 发给开发者：每次没经过翻译的发送都会记下原因。
